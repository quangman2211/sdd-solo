# UC-000 — Sequence

Only create this when the UC crosses a network boundary or talks to an external system. Draw timeout, retry, idempotency — the things the flowchart in `UC-000.flow.md` does not say clearly.

sequenceDiagram
  autonumber
  actor U as <Actor>
  participant C as <Client / device>
  participant API as <API>
  participant D as <Domain>
  participant X as <External system>
  U->>C: <action>
  C->>API: <request> {idempotencyKey}
  API->>D: <use case>()
  D->>X: <outbound call>
  alt success
    X-->>D: ok
    D-->>API: result
    API-->>C: 2xx
  else <exception E#>
    D-->>API: reason
    API-->>C: 4xx {reason}
  end
