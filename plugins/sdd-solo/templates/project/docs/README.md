# docs/ — quyết định kỹ thuật và vận hành

- `adr/` — Architecture Decision Record, một file một quyết định, không sửa; đổi ý thì viết ADR mới, đánh dấu cũ superseded.
- `decisions.md` — bảng tra một dòng cho mọi quyết định kỹ thuật, append-only. Trỏ tới ADR hoặc `design.md` của lát.
- `architecture.md` — C4 Context/Container + sơ đồ Hexagonal (khi cần).
- `design-system.md` — link canvas Design System trên Claude Design + token chính.
- `runbooks/` — chạy, deploy, xử lý sự cố.
- `onboarding.md` — chạy dự án thế nào; viết cho chính mình sau ba tháng.

Bài test: khách hàng có cảm nhận được không? Có → không phải doc, là spec.
